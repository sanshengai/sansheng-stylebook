# 图型怎么选：先问关系，再问几条

文章插图、信息图、PPT 页型、小红书内页共用这一张决策流。来源是调研报告 04（Dan Roam 的 6W、SQVID 五问，及各开源项目的图型库），具体文字量数字是建议值，待回测。图型的版式几何在 `structures/structures.json`，这里只管「选哪个」。

## 决策流（命中即停）

```
Q1 核心是「一个判断」还是「几件事的关系」？
   一个判断，无并列无顺序      → 概念隐喻场景 或 金句卡
   几件事的关系                → 继续
Q2 有先后吗？
   有，终点不回到起点          → 线性流程 / 时间线
   有，最后回到起点            → 循环
Q3 有两个对象在同一维度上对举吗？
   两个不同对象                → 二元对比
   同一对象的前后变化          → 前后对比
Q4 有两条独立维度，且有 3 个以上条目要「放置」吗？
   有                          → 四象限
Q5 有层级、包含、量递减或表里关系吗？
   层级与基础 → 金字塔；量递减 → 漏斗；表里 → 冰山
Q6 一个中心配几个方面，还是多对多的影响？
   一个中心 → 中心辐射；多对多 → 关系网
Q7 以上都不是：N 个并列、互不依赖、无顺序无对比轴 → 并列清单
```

「有四条」不等于四象限，「有三条」不等于清单。同一段含多种结构时选一个主图型，至多再加一种辅助。结构不成立或重点是情绪、转折，才用概念隐喻（找一个动作：掀开、穿过、筛掉、对准、埋下，别写成「画面里有 A、B、C」）。

## 三个容易选错的形式

- **对比图**：条件是能写出「同一维度下 A 是 x、B 是 y」至少两句；比较维度 ≤ 3；两侧信息单元数量能对齐。超过两个对象改用象限或表格；对举只是修辞改隐喻；两侧严重不对称改前后对比。
- **四象限**：条件是两条独立、可分高低的维度，加 3–8 个条目要被放置。判别测试：每一格的名字能否由「维度 A 的取值 × 维度 B 的取值」直接推出。推不出就是把四条并列要点硬排成田字格，其实是清单。
- **人物指出几个要点**：它是呈现皮肤，不是图型。内容先得是一张并列清单或行动清单，再看值不值得加人物。条件：3–5 个互不依赖的要点；平台适合竖版图文；画风里有固定人物且一致性可控；每个要点 ≤ 12 字。要点有顺序用流程，有对比用对比，含数据用结构图；去掉人物后结构仍成立才合格。人物只做三件事：操作关键对象、指示阅读方向、提供尺度，占画面 10%–20% 以内。

## 图型表（文字量是建议值）

| 图型 | 回答什么 | 内容信号 | 文字量 |
|---|---|---|---|
| 二元对比 | 两者在同一维度哪里不同 | 不是……而是……、A 与 B | 维度 1–3；每侧每条 ≤ 12 字 |
| 前后对比 | 同一对象发生了什么变化 | 从……到……、以前……现在…… | 两栏各 1–3 条 |
| 并列清单 | N 个互不依赖的要点 | 三点、五个方法、几个误区 | 3–5 项；标题 ≤ 6 字，说明 ≤ 16 字 |
| 四象限 | 条目落在哪一格 | 高低两轴、优先级、定位 | 2 个轴标 + 4 格名 + 3–8 个条目（每个 ≤ 6 字） |
| 线性流程 | 按什么顺序发生 | 先、再、然后、步骤 | 3–5 个节点（最多 7） |
| 循环 | 如何形成回路 | 反复、闭环、飞轮、复盘 | 3–5 个节点，每个功能不同 |
| 时间线 | 何时发生了什么 | 年份、阶段、里程碑 | 3–6 个点 |
| 金字塔 | 谁在上谁在下 | 基础与上层、优先级 | 3–5 层，每层 ≤ 8 字 |
| 漏斗 | 多如何变少 | 筛选、转化、层层淘汰 | 3–5 段；有数字时宽度成比例 |
| 冰山 | 表面下藏着什么 | 表面……实际…… | 水上 2–3，水下 3–5 |
| 中心辐射 | 一个中心有哪些方面 | 围绕某概念的几个方面 | 中心 ≤ 6 字；分支 3–6 |
| 关系网 | 对象之间如何影响 | 影响、依赖、导致 | 节点 ≤ 7，有方向必画箭头 |
| 韦恩 | 重叠部分是什么 | 既是 A 又是 B | 2–3 个集合，交集标 1 个 |
| 架构 | 系统由哪些层和模块协作 | 模块、输入输出、数据流 | 每层 ≤ 4 个模块 |
| 天平/光谱 | 两端之间如何取舍 | 取舍、程度 | 两端标签 + 1–3 个中间位置 |
| 大数字 | 有多大 | 具体数字、比例 | 1–2 个数 + 一句标签；只有一个值就不要画图表 |
| 概念隐喻 | 一句判断让人理解什么 | 单一判断、情绪、转折 | 0–5 个标签，每个 2–4 字 |
| 分镜/四格 | 前后变化、踩坑复盘 | 失败到成功、转折 | 2–4 格，每格一个动作 |
| 行动清单 | 读完今天能做什么 | 今天就能做、步骤要落地 | 3–7 项，每项以动词开头 ≤ 14 字 |
| 金句卡 | 先记住一句话 | 反常识判断 | 一句 ≤ 20 字 |
| 等式 | 几个要素如何组成结果 | A + B = C | 2–4 个要素 |

## 通用丑做法（出图前对照，出图后核对）

- 规则网格里填满同形圆角盒和等粗箭头，一眼像 PPT：至少要有一个主导对象和疏密对比。
- 在图里写图型标题（「流程图」「系统架构」）：图里的字只负责定位结构。
- 同一篇文章同一图型反复出现：至少一半换形式。
- 去掉文字标签后结构就不清楚（违反「无文测试」）。
- 单个模块占画面超过约 15%–20%，或最粗线、最多细节、最强颜色同时落在一个模块上。
- 象限没有轴标签；金字塔宽度与含义无关；漏斗宽度与数字不符；循环里四个相同图标围成圈；人物居中占大半、要点碎成光环。
- 隐喻用烂大街的机器人、大脑、电路板、火箭；或用与原文无关的通用意象（船、路、山）替代原文指纹。
- 整体检验（Tufte 擦除测试）：任何擦掉不损失信息的元素都应该擦掉。
