# 出图后检查表

写法固定为「缺陷 → 修复 → 复检」，记进本次的验收记录。机器通过不等于视觉通过；高影响判定看两次（同一看图员对同一张图会前后不一致）。命令与绑定细节见 [qa.md](../qa.md)。

## 每张图

| 检查 | 方法 | 不通过怎么办 |
|---|---|---|
| 尺寸比例与要求一致 | 读文件，如实报告原生尺寸 | 重出，不谎称已达某尺寸 |
| 清单里每条文字逐字出现，数字逐位核对 | 原尺寸看图逐字对清单 | 少错单张重出；错得多减字后重出 |
| 没有清单外的文字、乱码、英文残留 | 同上 | 同上 |
| 内部约束没被画出来（色值、字体名、制作指令） | 同上 | 写成「不得渲染」重出 |
| 缩到 360 px 宽：主体和标题还认得出，最小字 ≥ 12 px 等效 | 缩略图 | 减字、放大主体 |
| 三秒一眼：只给图，能说出这张的主旨 | 另开一次看图，不给原文 | 重新构思图型 |
| 无文测试：遮住文字，结构还清楚吗 | 遮字后看 | 换图型 |
| 溢出、遮挡、贴边、文字压住主体 | 看图 | 修底图或排字布局，不能压主体 |
| 人物：手脚数量、脸是否串味、有没有现成角色 | 原尺寸逐人数 | 另开候选目录重出，失败候选保留 |
| 参考图串味：画面里出现参考图里的人物、物件、文字、版式 | 对照参考图 | 换参考图或加隔离说明 |

## 整组

- 接触表一眼看：背景色不漂、字号光学一致、同类图视觉分量相近。
- 只读标题：把所有标题连读，是否自成一个故事。
- 图型重复与节奏：相邻页型不同；同一页型在连续 8 页里不超过 2 次；连续信息密集页不超过 3 页后放一页低密度页。
- 数量与计划一致；每个入围段至少一张图，没有对应不到计划的孤儿图。
- 画面里每个数字和引语都能在原文找到。

## 返修阶梯（每张累计不超过 3 次）

1. 同提示词重抽 1 次（偶发错字）。
2. 缩短文案后重出（字错或挤压，先减字）。
3. 拆页（字数超预算、两类证据挤在一页）。
4. 换更简单的图型或页型（复杂版式反复失败）。
5. 改成「无字底图 + 程序排字」，不要反复重抽密集数字表。
6. 请用户从不完美的候选里二选一。

返修原则：改图先改提示词再重出；新文件新路径，保留坏候选；风格块、参考图或合同一改，整组旧验收失效。

## 状态词

concept（概念）/ draft（草稿）/ candidate（候选）/ release（可发布）/ blocked（缺条件）。预检通过不等于成品；缺生图工具就标 blocked，不假装完成。
