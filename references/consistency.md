# 从一而终：画风与角色贯彻 · 规格

> 状态：最小可用已实现（`scripts/stylebook/character.py`、`sb.py character`）。

## 用法

1. 写角色圣经 `character.json`：`id`（小写英文）、`name`、`desc`（一句外形概述）、`markers`（至少 3 条辨识特征，至少 2 条靠形状或标志物，如「头顶两个小圆发髻」「一枚月牙发夹」；只靠颜色的会被拒收，因为颜色会被样式色板改掉）。描述里不写具体的未成年年龄（如「12 岁」），写「年轻学生」「孩子」即可——带参考图改图时，具体年龄加儿童形象容易被服务方审核拦截（2026-09-25 实测同一场景连拦三次，去掉年龄当次通过）。
2. `python3 scripts/sb.py character sheet character.json --style C58` 出设定网格（正、侧、背全身 + 三种表情）。
3. 之后每张图的清单里写 `content.characters` 与 `references: [{"path": 设定网格, "role": "identity"}]`。
4. 出完几张后（背影等角度看不到的特征不算缺失；网格标签按应有文字比对） `python3 scripts/sb.py character check character.json 设定网格 图1 图2 … --style C58`：拼对照网格（第一格设定网格），独立看图逐条核对每条辨识特征。
5. 系列项目写 `stylebook.project.json`（`character.project_lock`）：风格码必须带修订号（如 `C58@r1`），合同升级时编译会拦下先问。

## 画风

锁定层原样贴 + 同一张锚点图 + 修订号锁定 + 系列圣经继承；系列中途合同升级不自动跟进，先问。批量计划可写 `"series": {"id": "项目内稳定 ID", "master_id": "正文图 ID"}` 指定母版；小红书、PPT、文章配图和绘本页会自动视为系列。混合封面与正文时优先正文作为母版，避免封面特殊构图支配正文。只有母版导出及独立看图均通过，后续图才引用其 raw 图；未验收或失败时后续项标记 `blocked`。参考图内容变化会让缓存失效。

## 角色

- 角色圣经：外形靠形状与标志物区分（不能只靠颜色），做剪影测试。
- 一次生成整张设定网格（正、侧、背、表情），之后按景别配参考图。
- 属性隔离：每个角色的描述只写一次，多人画面给角色编号分工，或分别生成再合成。
- 改图就编辑定稿图，不重抽。

## 验收

逐条特征判断 + 一致性对照网格（第一格放定妆图）+ 重试上限；指标是每张可用图的平均重跑次数。
