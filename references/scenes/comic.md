# 漫画（四格、条漫、整册）

场景 id `comic4`，格式 `comic-4panel`、`comic-webtoon`、`comic-mixed-page`、`comic-manga-page`、`comic-splash-page`。角色一致性读 [consistency](../consistency.md)。**漫画班底一律原创**，不得出现现成动漫角色名，提示词里写「只用原创角色」。

## 单页（现有）

- 四格（`comic-4panel`）：起承转合，第三格是反转或顿悟、最重；正好 4 格，不加标题格；2×2 等大，间隙 8–10 px，Z 形阅读；每格换景别，对白写进对应那一格的描述里。
- 知识条漫（`comic-webtoon`）：学生加老师两个原创角色，用一个类比讲清一件事，最后一格是结论框。
- 日漫混排页：斜切格、跨格、人物破格、一个出血大格。
- 每格写景别、场景、时间光线、动作表情；对白每格一两句，每句 ≤ 12 字，全页 ≤ 6 句。人物靠道具区分，最多两三个。

## 整册流水线（多页漫画，如知识漫画、人物传记）

```
分析 → 分镜文档 → 角色设定 → 角色参考表 → 逐页出图 → 检查
```

1. **分析（六维加自检）：** 主题与读者；要讲的 3–7 个核心概念（每个必须能变成一件道具或一个场景）；叙事结构；情绪曲线；信息量与页数；风险（事实、历史准确性、版权）。
2. **页数三档：** 短故事 5–8 页、中等 9–15 页、完整 16–25 页。
3. **分镜文档（逐页一份）：** 叙事层、本页核心信息一句话、格布局、逐格（景别、场景、时间光线、动作表情、对白）、页末钩子（让读者翻页的悬念）。用户确认分镜后才出图；增删页只改序号，不改页的名字，引用不断。
4. **角色设定：** 脸型、发型、固定服装配色、标志道具、4 种表情、年龄变体；至少 3 条辨识特征，其中至少 2 条靠形状或标志物；剪影测试（只看剪影能分清是谁）。出一张角色参考表，之后每页都挂这张表。
5. **逐页出图：** 先出第 1 页和一张有代表性的内页，通过看图验收后锁定，其余并行；每页带角色参考表和母版页；对白逐格逐字核对。
6. **检查：** 逐页对照分镜（格数、景别、对白）；整册跨页对照角色（脸型、服装配色、标志物）；历史题材查考服饰、技术、建筑，人物按年龄变体。

## 叙事预设（预设 = 组合 + 不可协商的规则）

- **知识漫画：** 每个技术概念必须变成一件道具或一个可进入的空间；禁止「对着黑板讲」的说话头；道具揭晓四步（出现、被误用、被理解、被运用）；结尾要有四样：一句结论、一个可带走的动作、一个回扣开头的画面、一个未解的问题；页标题是叙事式而不是章节名；班底原创（一个好奇的学生加一个爱打比方的老师，不得像任何现成角色）。
- **概念漫画：** 先写「概念 → 符号」映射表；符号连续性三阶段：首次柔光出现、后续在背景复现、结尾汇聚；五幕成长弧；每页至少 1 个对话格加 1 个行动格；不连续超过 4 格讲课。
- **四格寓言：** 点缀色系统（黑白线稿加一个点缀色，第三格最强）；第三格最重；严格 4 格，不许第 5 格。

## 检查

`python3 scripts/sb.py comic-book 分镜.json` 检查分镜文档：页数档位、逐格景别与光线、对白长度、页末钩子、概念到道具的映射、连续讲课格、结尾四要素、页标题、角色圣经与现成角色名。分镜文档格式见 `scripts/stylebook/comic_book.py` 的头注释和 `tests/test_comic_book.py` 里的样例。角色参考表挂载与整册跨页对照仍用 `sb.py character`。
