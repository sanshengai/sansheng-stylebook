画风库

一句话，让 AI 按你选的画风出整组图

叁笙生图是一个出图 Skill：在这里挑好用途、画风和色系，复制一行码交给装了它的 Agent，文章配图、封面、小红书卡片、PPT 就按同一套画风画出来。本页是挑选的地方，网页本身不出图。

GitHub

怎么用

How it works先装 Skill，再来这里挑
1

安装 Skill （必须先装）

从 GitHub 安装（推荐）

npx skills add sanshengai/sansheng-image -g

复制这一行到电脑终端执行（需要 Node.js），装完重开 AI 助手。不会用命令行？把这句话发给你的 AI 助手，让它替你装：

请从 GitHub 安装叁笙生图 Skill：https://github.com/sanshengai/sansheng-image

觉得好用，去 GitHub 点个星。

完整出图需要 Claude Code、Codex 这类能在电脑上执行命令的 AI 助手。

打不开 GitHub？

从本站的「宝藏页」下载 zip 镜像包，解压后对你的 AI 助手说：把这个文件夹装成 Skill。

本站宝藏页（zip 镜像）
其他装法
Claude Code，在对话里依次输入
/plugin marketplace add sanshengai/sansheng-image
/plugin install sansheng-image@sansheng-image-marketplace
手动下载
git clone https://github.com/sanshengai/sansheng-image.git
2

在这里挑

选用途、画风、色系，点「复制给 AI」，得到一段能直接发给 AI 助手的话，里面带着一行码：

sb2:xhs/C30-ocean

想先看效果，往下逛画廊，或点「帮我挑」回答三个问题。

3

交给 Agent

把这行码和你的文章或主题一起发给装了 Skill 的 Agent。它会规划、出图、逐张检查，同一系列的图保持同一个画风。

每个色系都有名字和故事，像一年一度的流行色。挑中了点「用这个色系」，之后在画风详情里会默认选中它。每个色系下面是用它真实画出来的三张图（人物、静物、信息图），点图可以看对应画风。
